# Front-end Radar dos Preços

Interface React/Vite em português para selecionar e salvar a cesta, consultar coletas e comparar preços.

Veja o [README principal](../README.md) para instalação, configuração da API, agendamento e limitações.

- `npm run dev`: servidor de desenvolvimento.
- `npm run lint`: ESLint.
- `npm run build`: build em `dist`.
- `npm run preview`: preview do build.
- `VITE_API_URL`: endereço da API (padrão `http://localhost:3000`).

A interface usa a lista inicial fornecida pelo back-end e não mantém um catálogo duplicado.
